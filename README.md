# MacroCraft releases

Public distribution repository for **MacroCraft** Android application downloads.

Official build source is the private `The1Kmacho/macro-craft` repository. Only verified Android APKs, checksums, and release metadata are intended for publication here. No private application source, signing keys, or credentials should be committed.

Download a build from the [GitHub Releases page](https://github.com/The1Kmacho/macro-craft-releases/releases). Alpha, Beta, and Preview builds are experimental; Stable builds are production releases.
